# Fontes e licenças dos dados

Este projeto não redistribui APKs nem arquivos de jogos e aplicativos.

Os dados de `data/games.json` e `data/apps.json` são apenas links e metadados para fontes oficiais:

- Google Play: links de página de aplicativo (`play.google.com`).
- GitHub: repositórios oficiais dos projetos (`github.com`), cujos termos de uso e licenças valem para o código de cada projeto.
- Sites oficiais dos desenvolvedores ou projetos (ex.: f-droid.org).

Os nomes de aplicativos e marcas pertencem a seus respectivos titulares. O código deste projeto
não tem licença definida pelo autor; antes de publicar, escolha uma licença (por exemplo MIT).
Os metadados foram escritos a partir de conhecimento geral e **não foram verificados ao vivo** nesta entrega
(campo `last_verified` vazio). Use `scripts/validate_links.py --online` para testar os links.
